## Brand & Style

The design system establishes a high-trust, defense-grade institutional environment for workforce behavioral analytics, risk modeling, and compliance oversight. The aesthetic merges precision engineering with institutional authority, eliminating decorative clutter in favor of high information density, structural legibility, and unambiguous hierarchy.

### Target Audience & Emotional Tone
Designed for HR executive leadership, workforce risk analysts, and organizational integrity officers handling sensitive human capital datasets. The interface conveys uncompromising privacy assurance, algorithmic objectivity, and administrative command. It feels analytical, balanced, and non-stigmatizing—avoiding sensationalist threat language through calm, data-first visual grammar.

### Design Movement: Institutional Utility & Editorial Precision
Drawing from modern technical minimalism and defense workstation interfaces:
- **Structural Density:** Compact, space-conscious layouts engineered for data-heavy inspection tables, cohort matrices, and explainability breakdowns.
- **Architectural Framing:** Subdued dividers, structured bounding boxes, and precise hairline rules replacing floating cards and soft shadows.
- **Clinical Demarcation:** Strict semantic separation between administrative commands, statistical anomalies, and pseudonymized individual profiles.

## Colors

The palette is anchored in deep evergreen tones, balanced against muted slate-sage undertones and warm parchment backgrounds. This eliminates sterile laboratory glare while maintaining maximum contrast for extended analytical sessions.

### Core Swatches
- **Primary (`#1B4332`):** Primary brand anchor. Used for primary interactive triggers, institutional headers, verified badges, and navigational state anchors.
- **Secondary (`#2D6A4F`):** Structural support color for focused table rows, secondary controls, active tab indicators, and progress tracks.
- **Tertiary (`#087F8C`):** Predictive engine accents, automated inference indicators, SHAP factor markers, and machine learning telemetry data.
- **Neutral Deep (`#2B3330`):** High-contrast text, column headers, and structural border framing.

### Surface Architecture
- **App Canvas (`#F9F9F6`):** Warm mineral base canvas ensuring calm viewing across high-density layouts.
- **Surface Level 1 (`#FFFFFF`):** Workstation panels, data tables, and batch upload zones.
- **Surface Level 2 (`#F0F1ED`):** Inactive inputs, table header groups, code/ID snippets, and sidebar tracks.
- **Surface Highlight (`#E4E7E1`):** Inset data cells, focused borders, and divider lines.

### Semantic Risk Accents
- **Valid / Normal (`#13734B`):** Cleared thresholds, passed batch ingestions, baseline stability.
- **Review / Anomaly (`#B76E00`):** Deviation detection, schema warnings, flagged variance requiring review.
- **Elevated / Critical (`#B42318`):** Threshold breaches, schema mismatch rejections, integrity alerts.
- **Predictive Inference (`#0E7490`):** Probabilistic confidence intervals, regression shifts, automated scoring badges.

## Typography

The type scale balances rapid data scanning with structural durability. Set entirely in Inter, the system relies on typographic weight, micro letter-spacing adjustments, and compact line heights to maintain legibility in compressed interfaces.

### Hierarchy Guidelines
- **Display & Headlining:** Reserved for aggregate metric overviews, portal tier modules, and security audit titles. Letter spacing is condensed (`-0.02em` to `-0.01em`) to create a grounded, commanding presence.
- **Body & Records:** Default body font size is anchored at `13px` for high-density tabular environments. This allows 30+ records visible above the fold on desktop terminals without visual crowding.
- **Monospace & Code Equivalents:** Pseudonymized hashes (e.g., `UID-99418-E2`), SHAP feature contribution values, and file checksums leverage `code-md` (`12px` medium, zero-kerning) with tabular figure alignment enabled.
- **Labels & Overlines:** Category headers, table sort handles, and operational state labels use uppercase `label-sm` or `label-md` with `0.04em` to `0.06em` tracking for rapid peripheral scanning.

## Layout & Spacing

A compact 12-column grid system designed around a base 4px metric grid (using 0.25rem increments). The layout prioritizes horizontal real estate to maximize the viewport width for multi-attribute analytics and lateral trend lines.

### Layout Model
- **Workstation Sidebar:** Fixed 240px navigation dock on desktop, collapsible to 64px icon-rail to expand tabular analysis space.
- **Main Canvas:** Fluid workspace with an inner max-width constraint of 1600px for wide desktop monitors, anchored by 24px outer margins.
- **Modular Data Cells:** Data panels conform to 3, 4, 6, 8, or 12 column modules separated by a tight 12px (`0.75rem`) gutter.

### Breakpoint Matrix
- **Mobile (< 768px):** Stacked single-column card flows. Dense data tables switch to responsive summary rows with drawer expansions.
- **Tablet (768px - 1024px):** 2-column metric cards; side-by-side SHAP correlation charts wrap below the main data table.
- **Desktop (1025px - 1440px):** Standard 12-column workspace with dual-panel views (cohort matrix alongside factor breakdown).
- **Ultra-Wide (> 1440px):** 3-pane layout: cohort filter panel (left), live pseudonymized grid (center), real-time anomaly telemetry inspector (right).

## Elevation & Depth

Visual separation relies on structural framing and subtle tonal stepping rather than dramatic shadows. This ensures crisp rendering on both defense-grade low-reflectance field monitors and executive conference displays.

### Layering Hierarchy
- **Level 0 (Canvas Base):** Muted `#F9F9F6`.
- **Level 1 (Card & Module Layer):** `#FFFFFF` surfaces defined by a 1px solid hairline boundary in `#E4E7E1`. Zero ambient drop shadow.
- **Level 2 (Interactive Flyouts & Filter Trays):** `#FFFFFF` with a crisp structural border (`#CBD2C6`) and a direct 2px contact shadow: `0 2px 4px rgba(43, 51, 48, 0.06)`.
- **Level 3 (Modal Ingestion & Audit Inspect):** `#FFFFFF` with perimeter frame (`#2D6A4F` top border accent) and deliberate scrim overlay (`rgba(27, 67, 50, 0.4)` with 2px backdrop blur).

### Focus & Hover Precision
Interactive components do not shift position on interaction. Hover states utilize background fills (stepping to `#F0F1ED`) and border tint transitions rather than vertical translation or heavy glow artifacts.

## Shapes

The design system employs a restrained `roundedness: 1` profile (0.25rem / 4px base radius) across interactive surfaces. This conveys structural discipline, geometric permanence, and programmatic stability.

### Radius Assignments
- **Base Components (Inputs, Buttons, Badges):** `4px` (`0.25rem`). Clean corners that nest tightly within compressed operational toolbars.
- **Containers & Data Panels:** `4px` (`rounded-sm`). Maximizes corner space efficiency for dense column headers.
- **Dropzone Area:** `4px` border boundary using a 1.5px dashed stroke with 8px dash-to-gap ratio.
- **Inline Status Pills:** Full pill shapes (`9999px`) are strictly avoided. Status pills maintain a consistent `4px` corner to integrate seamlessly with adjacent tabular metrics.

## Components

### Buttons & Operational Actions
- **Primary Action:** Solid `#1B4332` fill, `#FFFFFF` text, `4px` border radius, `32px` standard height, uppercase `label-md` text with `12px` horizontal padding. Hover: `#2D6A4F`. Active: `#143527`.
- **Secondary Action:** Transparent fill, `1px` solid `#CBD2C6` border, `#2B3330` text. Hover: `#F0F1ED` background fill.
- **Destructive / Flag Action:** `#FFFFFF` background with `1px` solid `#B42318` border, `#B42318` text. Hover: `#FEF3F2` background.

### Pseudonymized Table Rows & Lists
- **Row Anatomy:** `36px` compact row height. Zebra striping disabled in favor of `1px` solid `#F0F1ED` dividers.
- **Pseudonym Identifier:** Rendered in `code-md` using a muted `#56635D` text badge with a subtle `#F0F1ED` background container.
- **Selection State:** Checked rows apply a `2px` inset primary green border (`#1B4332`) along the left edge and `#F4F6F3` row background tint.

### Ingestion Dropzone (Tier 2 CSV/XLSX)
- **Dropzone Container:** `#FFFFFF` panel with `1.5px` dashed border (`#9CAAA2`). Height fixed at `140px` for compact panel nesting.
- **Active Drag State:** Border shifts to solid `#1B4332` with a `#EBF2EE` translucent background wash.
- **Inline Validation Chip:** Displays immediate row count parse, schema verification status (`Pass: 42/42 attributes matched`), and SHA-256 batch hash confirmation prior to execution.

### Predictive Model & SHAP Breakdown Modules
- **Factor Value Bars:** Split horizontal divergency bars (center-zero baseline). Leftward negative impact rendered in `#2D6A4F` (stabilizing), rightward elevated impact rendered in `#B76E00` or `#B42318` (anomalous contribution).
- **Inference Confidence Indicators:** Integrated `087F8C` tick marks representing 95% statistical confidence boundaries over historical rolling benchmarks.

### Input Fields & Filter Dropdowns
- **Field Height:** Standardized at `32px` to match button scale.
- **Styling:** `1px` solid `#CBD2C6` perimeter, `#FFFFFF` background, `#2B3330` font value, `8px` internal lateral padding.
- **Focus Ring:** Crisp, non-diffused `1px` solid `#1B4332` outer ring without ambient glow.
